# Spider web frontend

Static browser code for [Spider](https://mannyfluss.github.io/SpiderWeb/). Your saved state lives on your own Mac and devices. The site connects directly to a paired, reachable HTTPS Mac; it is not a relay. No saved state, credentials, Mac addresses, or pairing invitations are published here.

Built from the private Spider app repositories. These generated files also work from a local static host. Keep the whole directory to retain the frontend independently of GitHub.
