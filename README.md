# Spider web frontend

Static browser code for [Spider](https://app.strangeriver.org/). GitHub Pages hosts the frontend at its custom domain; the protected runtime and saved state live on your own Mac. Browsers retain connection details, window preferences and unsent edits. Remote requests require Cloudflare Access and independent Spider pairing. Public site configuration contains only the selected frontend and runtime addresses. No saved state, account/tunnel credentials or pairing invitations are published here.

Built from the private Spider app repositories. These generated files also work from a local static host. Keep the whole directory to retain the frontend independently of GitHub.
