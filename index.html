Check your connection

Mac address

Ready to check this browser’s connection.

    Open the Mac’s connection test

    If that page shows "app":"spider", the address is reachable. Over HTTPS, the browser has also accepted its certificate.

    Check the address and Wi-Fi
    1. Keep the Mac awake and Spider running.
    2. Connect the phone and Mac to the same Wi-Fi. A guest network may isolate devices.
    3. Run spider pair on the Mac. Compare the printed Mac address above, or scan the new QR to fill it in.
    4. If asked, allow this browser or website to connect to devices on your local network.
    Check certificate trust on iPhone or iPad
    1. Open Settings → General → VPN & Device Management. Check that your original Clay certificate profile is installed.
    2. Open Settings → General → About → Certificate Trust Settings.
    3. Under Enable full trust for root certificates, enable your Mac’s Clay local room CA certificate.
    4. Return to Spider and run this check again. If no Clay certificate is listed, install the original profile from your Mac first.

    A webpage cannot inspect or change iOS certificate settings. A successful HTTPS check confirms that this browser accepted the Mac’s certificate.

    Apple’s certificate-trust instructions

    The Mac answers, but the API is rejected

    Spider had a bug that rejected HTTP/2 API requests with “Unrecognized Spider address.” The page could load while its workspace failed. Update Spider on the Mac, then run this check again. Pairing errors are shown separately from connection failures.
